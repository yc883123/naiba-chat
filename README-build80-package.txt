Naiba Chat Build 80

This package contains the Windows x64 executable for Build 80.

Highlights:
- llama.cpp + mmproj models are detected from live runtime capabilities and receive original images directly.
- Text-only automatic visual routing no longer repeats vision_describe.
- Ordinary full-Agent chat uses progressive Tools and Skills disclosure instead of sending every schema.
- Lightweight mode has independent Tools and Skills switches.
- DeepSeek visual requests, context menus, reply selection/quick-send, and Markdown headings are supported.

The automatic updater verifies naiba-chat.exe against the SHA-256 value in
naiba-chat-update.json before installing it.
