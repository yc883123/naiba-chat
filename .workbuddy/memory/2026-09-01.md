## 下午：排障 + 安全加固（第二轮）

**400 排查结论**（手机访问报 400 Bad Request / "The plain HTTP request was sent to HTTPS port" / nginx/1.24.0）：
- 根因是**手机浏览器地址栏输 IP:端口 时默认走 http 明文**，打到仅支持 https 的 8443 → nginx 拒 400
- 解决：nginx 增加 8080 http 监听，`return 301 https://$host:8443$request_uri;` 做防呆跳转；防火墙放行 8080
- 另一个预防性修复：frp **tcpMux 多路复用疑似导致手机 keep-alive 长连接 400**（curl 短连接正常），两端配置 `transport.tcpMux = false`（frps.toml / frpc.toml 都加，**必须同时改，否则 frpc 报 `connect to server error: EOF`**）
- 排查中用到的命令：nginx access log 看手机真实 UA/IP、本机 curl 模拟手机头区分层（naiba-chat 直连 200 → 问题在 nginx 层）
