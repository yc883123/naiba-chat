Naiba Chat Build 87

This package contains the Windows x64 executable for Build 87.

Highlights:
- Skills are guidance-only and no longer decide NaibaChat's built-in capabilities.
- ComfyUI works without a Skill or MCP through the generic HTTP API or comfy CLI.
- Official comfy-mcp remains an explicit external integration and was verified with a local workflow.
- Skill scans are cached, Skill-relative reads are supported, and read-only file inspection needs no repeated approval.

The automatic updater verifies naiba-chat.exe against the SHA-256 value in
naiba-chat-update.json before installing it.
