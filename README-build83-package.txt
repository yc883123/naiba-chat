Naiba Chat Build 83

This package contains the official Windows x64 executable for Build 83.

Highlights:
- The Token usage popover is rendered outside the scrollable composer so its
  heading, context total, and latest-turn details are never clipped.
- The popover stays inside the viewport on narrow windows and scrolls
  internally when its content is taller than the available space.
- The tracked official-comfy-mcp Skill remains bundled as a default Skill.

The automatic updater verifies naiba-chat.exe against the SHA-256 value in
naiba-chat-update.json before installing it.
